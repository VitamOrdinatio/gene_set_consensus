# GSC Preservation Mission

## Purpose

This document defines the scientific preservation mission for the Gene Set Consensus (GSC) repository.

Its purpose is to guide future GSC-TEP construction by identifying the evidence, provenance, topology, context, and scientific meaning that must survive transport into downstream systems such as VDB.

This document is intended primarily for SAGE-GSC.

## Mission Statement

GSC exists to aggregate evidence from multiple biological knowledge sources and transform that evidence into phenotype-scoped semantic priors suitable for downstream interpretation and reasoning.

The preservation mission of GSC is:

```text
Preserve semantic evidence.

Preserve source provenance.

Preserve aggregation topology.

Preserve consensus meaning.

Preserve future reinterpretability.
```

## Summary

GSC is the ecosystem authority for phenotype-scoped semantic prior evidence.

Its preservation mission is to ensure that semantic priors, source attribution, consensus rationale, aggregation topology, provenance, and future interpretability survive transport into downstream systems.

The purpose of GSC-TEP is not merely to move consensus outputs.

The purpose of GSC-TEP is to preserve semantic evidence in a form that remains scientifically interpretable, provenance-rich, topology-aware, reproducible, and reusable by future repositories and future investigators.
